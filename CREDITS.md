# Credits

Neopact started as a team hackathon project (October 2026), originally developed across five repositories:
- the backend, the dashboard and a CLI;
- a Claude Code plugin and a Codex plugin.

This repository is a consolidated, slimmed-down rewrite. It has a fresh history and keeps the core marketplace, adding:
- a modular service layer;
- an owner rules editor;
- a shared HTTP MCP endpoint.
